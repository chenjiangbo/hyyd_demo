# 寰宇医道 Chrome 插件 — 自托管强制安装

> 目标：员工电脑装一次、以后自动更新；插件代码不经第三方（不上 Google 商店）。

## 架构

```
后端 47.95.14.233:9093
  ├─ /ext/update.xml            ← Chrome 定期来查"有没有新版本"
  └─ /ext/huanyu-extension.crx  ← 插件本体，由 update.xml 指向

员工电脑（Windows）
  └─ Chrome 企业策略 ExtensionInstallForcelist
       指向 update.xml → 自动下载 .crx 安装 + 保持更新
```

- **固定扩展 ID**：`akaojickfipoeobmiokkdbdaimeifmoa`（由 `packages/extension/key.pem` 私钥派生，写在 manifest 的 `key` 字段，永不变）
- **签名私钥**：`packages/extension/key.pem` —— **绝密，已 gitignore，务必本地/安全处备份。丢了就换 ID，所有员工要重装。**

## 一、首次上线（运维做一次）

### 1. 部署后端（带插件文件）
线上后端 `47.95.14.233` 必须是**最新代码**，且包含：
- 代码：`/ext/*` 静态托管路由（`packages/backend/src/index.ts` 已加）
- 文件：`packages/backend/public/ext/huanyu-extension.crx` + `update.xml`（已随仓库带）
- 数据库：`prisma db push`（确保有 `detail_fingerprint`、`order_state` 字段 + `order_status_history` 表）

部署后自检（任意机器）：
```bash
curl http://47.95.14.233:9093/ext/update.xml          # 应返回 XML
curl -I http://47.95.14.233:9093/ext/huanyu-extension.crx  # 应 200
```

### 2. 员工电脑安装
把 `packages/extension/release/安装插件.bat` 发给员工，**右键 → 以管理员身份运行**。然后：
1. 完全关闭 Chrome 再打开
2. 等 1~2 分钟，插件自动出现
3. 点插件图标，填各自的「员工 ID」，保存

> 卸载：跑 `卸载插件.bat`（管理员）。

## 二、以后更新插件（改完代码后）

```bash
# 1. 改 packages/extension/public/manifest.json 的 version（必须递增！如 1.2.0 → 1.2.1）
# 2. 打包
node scripts/pack-extension.js
# 3. 把 release/ 下两个文件复制到后端并部署
cp packages/extension/release/{huanyu-extension.crx,update.xml} packages/backend/public/ext/
#    然后部署后端（让线上 /ext/ 拿到新文件）
```

Chrome 每隔几小时自动查 `update.xml`，发现 version 更高就静默更新。**版本号不递增 = 不会更新**，这是最常见的坑。

## 三、注意事项 / 坑

- **版本号必须递增**：每次发版改 manifest `version`，否则员工不更新。
- **http 明文**：update_url 和 .crx 走 http。企业策略强制安装允许 http；但 token/订单数据明文传输，建议后续给后端上 TLS、把地址换成 https（同时改 manifest `update_url`、`安装插件.bat` 里的 URL、`pack-extension.js` 的 `BACKEND_BASE`、后端默认 WS 地址）。
- **私钥 key.pem**：打包必须用它，丢失=换 ID=全员重装。务必备份。
- **强制安装的扩展员工无法手动删**（受策略管控），这是预期行为。
- **注册表序号**：脚本用了 `ExtensionInstallForcelist` 的序号 `1`。若该机器已有别的 Chrome 策略占用了 `1`，需改用别的序号。

## 四、相关文件一览

| 文件 | 作用 |
|---|---|
| `packages/extension/key.pem` | 签名私钥（绝密，gitignore） |
| `packages/extension/public/manifest.json` | 含固定 `key` + `update_url` |
| `scripts/pack-extension.js` | 一键打包 .crx + 生成 update.xml |
| `packages/backend/src/index.ts` | `/ext/*` 托管路由 |
| `packages/backend/public/ext/` | 线上托管的 .crx + update.xml |
| `packages/extension/release/安装插件.bat` | 员工端一键安装 |
| `packages/extension/release/卸载插件.bat` | 员工端卸载 |
